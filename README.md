# logger-app-installs

GitHub Pages landing page for first-time Logger Android installs.

**Live page:** https://jono1954.github.io/logger-app-installs/

WhatsApp this URL to new users. Do not send the raw Dropbox APK link —
WhatsApp treating that URL as an attachment can start two downloads.

The download button on the page points at the stable Dropbox alias
`Latest-Logger-Version.apk`. The Logger ship script
(`upload-release-apk.ps1`) updates `index.html` (version label and size)
after each APK upload.
