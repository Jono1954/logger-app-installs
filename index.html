Installation

If Logger is already on the phone, do not uninstall it. Android will offer Upgrade and keep jobs and licence.

If Logger is already on the phone, it may open briefly to remove old Logger APKs, then the download starts. If Chrome asks Download file again, open Logger once and tap Download again.

  1. Select Download Logger App.
  2. If the install says The file might be harmful, select Download anyway.
  3. When the download finishes, select the downloaded file name and tap Install or Upgrade.
